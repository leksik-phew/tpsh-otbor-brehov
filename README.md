# Telegram бот аналитики данных о видео (GigaChat + PostgreSQL)

## 📌 Описание проекта

Telegram-бот принимает вопросы на русском языке и возвращает **одно
числовое значение**, рассчитанное на основе данных о видео и их
снапшотах.

Архитектура решения:

-   🐘 PostgreSQL --- хранение видео и снапшотов
-   🤖 Telegram-бот (aiogram 3)
-   🧠 GigaChat API --- генерация SQL по естественному языку
-   🐳 Docker Compose --- полный запуск одной командой

Бот: 
- Принимает вопрос
- Отправляет его в GigaChat
- Получает SQL
- Валидирует SQL
- Выполняет запрос к PostgreSQL
- Возвращает число

## ⚙️ Настройка

### 1️⃣ Создать файл `.env`

Пример:

    BOT_TOKEN=...

    DATABASE_URL=postgresql://postgres:postgres@db:5432/postgres

    GIGACHAT_AUTH_KEY=...
    GIGACHAT_SCOPE=GIGACHAT_API_PERS
    GIGACHAT_MODEL=GigaChat-Pro
    GIGACHAT_VERIFY_SSL=false

> Важно: `GIGACHAT_AUTH_KEY` должен быть **без слова `Basic`**, только
> base64-ключ.

## 🧠 Принцип работы SQL-генерации

Промпт описывает:

-   Схему БД
-   Семантику delta-полей
-   Правила интерпретации времени
-   Требование вернуть один `SELECT ... AS value`

SQL дополнительно проходит валидацию:

-   Только SELECT
-   Без `;`
-   Только таблицы `videos`, `video_snapshots`
-   Обязательный алиас `AS value`

------------------------------------------------------------------------

## 📊 Логика расчётов

-   `*_count` --- итоговые значения
-   `delta_*` --- прирост между снапшотами
-   Прирост за период = SUM(delta\_\*)
-   Периоды задаются полуинтервалами `[start, end)`
-   Для "после публикации" используется `video_created_at`
